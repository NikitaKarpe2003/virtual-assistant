# Virtual-Assistance
Own Virtual Assistant
A futuristic, neon-themed virtual assistant front-end built with HTML, CSS, and JavaScript. Features a glowing interface, microphone button, animated visualizer, and dynamic message display — ready to connect with voice recognition or AI backend.

## Features

- Neon-styled title with multi-color spans
- Microphone button (Font Awesome used for the icon)
- Message display area for status messages (Listening, Processing, etc.)
- Simple audio visualizer bars (CSS/JS driven)
- Easy to connect to voice recognition / AI backend
